# Specs

每個 feature 一個資料夾：`NNN-<feature>/`。

| 檔案 | 負責者 |
|---|---|
| `intent.md` | PO |
| `questions.md` | elicitor 起草，PO 回答 |
| `spec.md` | spec_writer 起草，PO 核准 |
| `checklist.md` | Reviewer |
| `uml/*.puml` | uml_drafter 起草，PO 核准 |
| `traceability.md` | tracer 起草，Reviewer 審查 |

Spec Kit 的 `$speckit-specify` 可能使用不同的資料夾名稱。如果不同，以 Spec Kit 的實際結構為準，並更新 METHOD.md。
